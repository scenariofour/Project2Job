# Career Desk Project-to-Application Skill

Use one real AI project to create grounded application and interview assets for an early-career AI PM role.

## What it does

Input:

- one project
- one target role or JD

Output:

- Role Fit Map
- Project Highlights
- 2–3 resume bullets
- 30-second project introduction
- three interview follow-up questions
- One Next Build

## What it will not do

- invent metrics or ownership
- search and apply to jobs
- analyze many projects at once
- send messages
- maintain long-term state

## Install

Copy this folder into the Skill directory supported by your Agent host.

## Use

Ask:

> Analyze this project for a Junior AI PM application using Career Desk. The JD is in `jd.md`, and the project is in this folder.

The Skill can also run with the bundled default AI PM Role Standard when no JD is available.

## Privacy

The Skill is designed for local project access. Review your host Agent's model and data settings before using private material.
