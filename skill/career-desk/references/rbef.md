# Role-Backwards Evidence Framework

Use this order:

1. Role Reality
2. Hiring Signal
3. Project Evidence
4. Evidence Boundary
5. Career Translation
6. Evidence Upgrade

Canonical mapping:

```text
Role Task
→ Hiring Signal
→ Required Evidence
→ Project Artifact
→ Supported Claim
→ Career Output
```

Do not begin by rewriting resume language.

Begin by establishing role relevance and evidence.
