# Evidence Rubric

Statuses:

- Supported
- Partially Supported
- Inferred
- Not Found
- Conflicting
- Needs Confirmation

Rules:

- Planned work is not completed evidence.
- README claims need artifact support when possible.
- Code proves implementation, not user value.
- A tool call proves usage, not product judgment.
- Evaluation requires cases, criteria, and results.
- Improvement requires a before-and-after comparison.
- Ownership requires user confirmation or a project record.
- Missing evidence does not prove missing capability.
