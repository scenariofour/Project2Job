# Resume and Interview Outputs

## Resume bullets

Use supported facts only.

Preferred structure:

```text
Action or decision
+ system or product scope
+ method
+ measured result or validated artifact
```

When a result is unavailable, use a precise implementation or evaluation artifact rather than an invented metric.

## 30-second introduction

Cover:

- user problem
- project decision
- AI or Agent role
- validation
- current result or limitation

## Interview questions

Prioritize questions that test:

- why the problem mattered
- why AI or Agent was needed
- workflow and tool choices
- evaluation
- failure and change
- tradeoffs
- personal ownership

For each question, provide:

- supported answer ingredients
- source references
- missing evidence
