# Migration from v5

The previous package contained 138 files. That volume mixed:

- active product decisions
- future ideas
- implementation assets
- historical references
- duplicate descriptions
- interview materials
- backlog concepts

This version intentionally keeps:

- 14 active product documents
- a standalone Skill package
- shared schemas
- a small Agent interface scaffold
- starter evals
- five Work Orders

Removed or consolidated:

- duplicate PRDs
- separate documents for every adjacent concept
- inactive framework experiments
- broad connector plans
- repeated roadmaps
- extensive templates
- mock product code unrelated to the final MVP

The reduction does not remove AI PM concepts. `AI_PM_PRODUCT_AND_INTERVIEW_GATE.md` tracks where each concept must appear as implementation evidence, experiment evidence, or a justified exclusion.
