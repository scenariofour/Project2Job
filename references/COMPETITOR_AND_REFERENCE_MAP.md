# Competitor and Reference Map

## Career Desk's position

Most job-search products begin with:

- job discovery
- resume text
- application workflow
- interview delivery

Career Desk begins with:

- the target role
- one real project
- project evidence
- defensible career outputs
- project improvement

## Reference patterns

### ApplyPilot

Use:

- safe first run
- simple states
- low-friction onboarding
- Agent-host distribution

Do not copy:

- broad application execution in MVP

### Jane's First Intern Copilot

Use:

- short Skill entry
- on-demand references
- direct user artifacts
- honesty rules

Do not copy:

- resume, application, and cold-email breadth in one MVP

### Jobscan

Use:

- clear decision
- fast output
- visible missing areas

Improve:

- inspect project evidence behind the resume text
- avoid a dominant total score

### Resume Matcher

Use:

- editable source of truth
- transparent open-source product
- role-specific generation

Improve:

- project evidence and Agent PM interview depth

### Yoodli

Use later:

- question, answer, feedback, retry loop

Avoid in MVP:

- audio and delivery analytics

### Simplify and AIHawk

Lesson:

- automation creates clear saved time
- external-site execution creates high maintenance and risk

Decision:

- exclude auto-apply and browser automation

## Technical references

### OpenAI Skills

Use progressive disclosure:

- metadata first
- SKILL.md on selection
- references and scripts only as needed

### OpenAI Agents SDK

Candidate runtime for:

- tools
- guardrails
- sessions
- tracing

### MCP

Use for interoperability or measured connectors.

Do not use MCP as a badge or as a replacement for product contracts.

### Hello-Agents and OpenCode

Use as learning and architecture references.

Do not fork and relabel a mature agent as Career Desk.
