# WO-04 Evaluation and Pilot

Context set: `eval_and_pilot`

## Goal

Determine whether Career Desk is useful, reliable, and meaningfully better than its baselines.

## Deliver

- completed gold set
- Skill vs prompt report
- Agent update vs fresh Skill report
- token and cost report
- bad-case log
- reviewer disagreement record
- small target-user pilot
- continue, change, or stop decision

## Acceptance

- targets and measured results are separated
- severe errors are listed
- user actions are measured
- architecture decision follows evidence
- portfolio case study uses only achieved results
