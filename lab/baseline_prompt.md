# Strong Generic Prompt Baseline

Read one AI project and one target AI PM JD.

Identify the role capabilities this project genuinely supports. Use only facts present in the supplied project materials. For every important claim, cite the source file and location. Distinguish supported, partially supported, inferred, missing, conflicting, and needs-confirmation claims.

Then produce:

1. a role fit map
2. 3–5 project highlights
3. 2–3 resume bullets
4. a 30-second project introduction
5. three interview follow-up questions with answer ingredients
6. one highest-priority project action with acceptance criteria

Do not invent users, metrics, results, ownership, decisions, or experiments. Missing evidence does not prove missing ability.
