# Project2Job Build Journal

This journal is the public Day 0–Day 7 learning and implementation narrative.
It records questions, intended user value, evidence, tradeoffs, and decisions
without duplicating the product specifications.

The technical source of truth remains:

- `ACTIVE_SCOPE.md` for the current MVP boundary
- `PROJECT_MANIFEST.json` for context selection
- `docs/00_PRODUCT_NORTH_STAR.md` through `docs/13_DECISION_LOG.md` for active product decisions
- `work_orders/` for engineering dependencies and acceptance criteria

## Status meanings

- `PLANNED`: scoped, but not implemented or tested
- `IN PROGRESS`: work has started, but acceptance criteria are incomplete
- `IMPLEMENTED`: required repository artifacts and checks exist
- `VALIDATED`: measured product or system evidence supports the claim

`IMPLEMENTED` does not imply user value, model quality, latency, cost, or
adoption has been validated. Those remain targets until measured.
